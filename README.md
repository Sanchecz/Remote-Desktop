# RemoteIt

RemoteIt — частная платформа удалённого администрирования Windows 10/11/Server, Ubuntu/Linux и macOS. В состав входят адаптивная веб-панель, настольная консоль, PWA, Windows Agent и Android APK.

## Рабочие адреса

- Панель: `https://supportgenesis.ru`
- Android: `https://supportgenesis.ru/downloads/RemoteIt.apk`
- Windows Agent: `https://supportgenesis.ru/downloads/RemoteIt-Agent-Setup.exe`
- Windows Console: `https://supportgenesis.ru/downloads/RemoteIt-Console.exe`
- Установщик Ubuntu/macOS: `https://supportgenesis.ru/downloads/install-remoteit.sh`
- Контрольные суммы: `https://supportgenesis.ru/downloads/SHA256SUMS.txt`
- Сертификат подписи Android: `https://supportgenesis.ru/downloads/APK-SIGNER.txt`

## Реализовано

- Автоматическая регистрация устройств по ограниченным установочным токенам и постоянный Remote ID.
- Публичная установка по коду или ссылке `#install=` без доступа пользователя к административной панели.
- Windows-служба в Program Files, приложение Agent в системном трее и автоматический запуск вместе с Windows.
- Системная установка через UAC и безопасный пользовательский режим, когда административные права недоступны.
- Установка в Linux через systemd и в macOS через LaunchDaemon.
- Автоматическое обновление Agent по HTTPS с обязательной проверкой размера и SHA-256 до замены исполняемого файла.
- Инвентаризация: публичные и локальные IP, ОС, архитектура, пользователь, процессор, RAM, диск, uptime и статус связи.
- Повторное подключение и обновление сетевых параметров после смены VPN, маршрута, IP или сетевого интерфейса.
- Пользователи и роли Owner/Admin/Technician/Viewer, CSRF-защита, Argon2id и принудительная замена временных паролей.
- Отдельный пароль устройства, задаваемый только владельцем. Владелец сохраняет доступ, остальные администраторы и техники разблокируют устройство в своей сессии панели.
- Немедленное удаление отключённого устройства только из панели с отзывом его текущих ключей, а также отдельная очередь подтверждённой полной деинсталляции Agent.
- Переименование, группы, отзыв токенов, отключение пользователей, смена паролей и журнал аудита.
- Три темы интерфейса: бело-зелёная по умолчанию, тёмная и системная.
- Настольная `RemoteIt-Console.exe` с изолированным профилем входа.
- Рабочее пространство «Удалённый доступ»: бесшумный предпросмотр, явное включение управления, полный экран, вписывание экрана, масштаб и Auto/15/30/60 FPS.
- Переключение между компьютерами без возврата на страницу устройств и сворачивание выбранного предпросмотра повторным нажатием.
- Разные мобильные режимы управления: прямое касание и виртуальный курсор; масштабирование двумя пальцами и адаптация к портретной/альбомной ориентации.
- Удалённая мышь скрывается при прямом управлении с ПК и сенсорном режиме; в режиме мобильного курсора остаётся видимой.
- Терминал с платформенными оболочками и оформлением: PowerShell/CMD для Windows, Bash для Linux, Zsh/Bash для macOS. Сервер отклоняет несовместимую с ОС оболочку.
- Постоянная очередь заданий терминала, тайм-ауты, отмена, ограниченный вывод, повторные попытки и аудит.
- Готовые сценарии диагностики системы, сети, процессов, служб и дисков.
- AI-администратор с контекстом устройства, планом разрешённых диагностик и обязательным подтверждением изменяющих состояние команд.
- Удалённый файловый менеджер с навигацией, возобновляемой загрузкой перетаскиванием и потоковым скачиванием файлов до 10 ГиБ. Транспортные части по 8 МиБ не удерживают весь файл в памяти.
- Android WebView-приложение, ограниченное производственным доменом RemoteIt, с системным выбором файлов и Download Manager.
- Ежедневные резервные копии PostgreSQL, защищённого `.env` и материала подписи Android с локальным хранением семь дней.
- Переносимый релиз без секретов и отдельный экспорт состояния для миграции на другой сервер.

## Права ролей

| Действие | Владелец | Администратор | Техник | Наблюдатель |
|---|---:|---:|---:|---:|
| Просмотр устройств | Да | Да | Да | Да |
| Инвентаризация | Да | Да | Да | Нет |
| Удалённый доступ | Да | Да | Да | Нет |
| Удалённый терминал | Да | Да | Нет | Нет |
| Просмотр истории команд | Да | Да | Нет | Нет |
| Управление устройствами и токенами | Да | Да | Ограниченно | Нет |
| Управление администраторами | Да | Нет | Нет | Нет |
| Журнал безопасности | Да | Да | Нет | Нет |
| Пароль отдельного устройства | Да | Нет | Нет | Нет |

Разблокировка защищённого устройства действует четыре часа только в текущей сессии панели. Выход, отзыв сессии, ручная блокировка или смена пароля отменяют доступ. Изменение защиты завершает не-владельческие удалённые сеансы и отменяет задания и передачи файлов этого устройства.

## Установка Windows

Скачайте `RemoteIt-Agent-Setup.exe` или готовый Agent со встроенным токеном на странице «Токены» и запустите двойным кликом. Обычная установка показывает одно окно RemoteIt и стандартное подтверждение UAC; PowerShell и консоль не открываются.

Тихое развёртывание из уже повышенного процесса:

```powershell
RemoteIt-Agent-Setup.exe setup --quiet --token "INSTALL_TOKEN" --name "Имя компьютера"
```

Для установки без прав администратора добавьте `--user-mode`. Если системный тихий установщик запущен без повышения, Windows всё равно показывает обязательное системное окно UAC.

При ошибке установщик сохраняет понятную причину и журнал без токена в `%ProgramData%\RemoteIt\Agent\install.log` либо в `%LocalAppData%\RemoteIt\Agent\install.log`.

## Установка Ubuntu/macOS

```sh
sh ./install-remoteit.sh --token "INSTALL_TOKEN"
```

Без `--name` установщик запрашивает название компьютера, а при неинтерактивном запуске использует hostname. Поддерживается `curl` или `wget`; выбранный бинарный файл обязательно проверяется по `SHA256SUMS.txt`.

## Эксплуатация

- Compose-проект имеет фиксированное имя `genesisit`.
- PostgreSQL не публикуется наружу.
- Публично открыты только SSH, HTTP и HTTPS.
- Контейнер приложения работает без root, с read-only файловой системой и без Linux capabilities.
- Инициализатор с минимальными правами подготавливает том передач; приложение не может писать в другие части контейнера.
- Контейнеры имеют healthcheck/restart policy и ограниченные Docker-журналы.
- Таймер резервного копирования: `genesisit-backup.timer`, примерно 03:20 ежедневно.
- Обслуживание Docker: еженедельно удаляются только build/image-данные старше семи дней.
- Резервные копии: `/opt/genesisit/backups`, доступ только root, хранение семь дней.
- Аудит хранится 180 дней, завершённые задания — 90 дней; просроченные сессии очищаются ежечасно.
- Нагрузочная проверка 300 параллельных heartbeat-запросов завершается без ошибок; фактическая задержка зависит от VDS и сети.

## Перенос и восстановление

Каждый выпуск формируется как переносимый комплект исходников и сборки без паролей, токенов и закрытых ключей. База, идентификаторы устройств, журнал, защищённый `.env`, ключ Android и незавершённые передачи экспортируются отдельно командой `ops/remoteit-export-state`. Защищённый сценарий восстановления отказывается работать на непустой целевой системе.

Полная процедура, проверки целостности и откат описаны в [docs/MIGRATION.md](docs/MIGRATION.md).

Проверка дампа без изменения БД:

```sh
pg_restore --list genesisit-YYYYMMDDTHHMMSSZ.dump
```

## Подпись и ограничения

Android APK подписывается release-ключом, который хранится только в защищённой серверной директории и передаётся BuildKit как secret. Публичный SHA-256 сертификата:

`d8a693ae3ae66393fa85cab9a14312106ac2c30d04d13742857a1392fbc1b2a6`

Windows EXE пока не имеет коммерческой Authenticode-подписи. Поэтому SmartScreen или браузер могут показывать предупреждение для нового файла с низкой репутацией. Убрать такие предупреждения гарантированно можно только выпуском через доверенный сертификат подписи кода; изменение имени, упаковки или интерфейса не заменяет подпись.

Удалённый рабочий стол использует транспорт последнего JPEG-кадра и отбрасывает промежуточные кадры вместо накопления задержки. Auto/15/30/60 задают целевую частоту, но реально достигнутые FPS и качество зависят от разрешения 1080p/2K/4K, производительности удалённого ПК и канала связи. Захват защищённого рабочего стола Windows/UAC в текущую границу сеанса не входит.

# 3x-ui + Happ — переносимый выпуск `v1.0.1` без пароля

Это стабильная конфигурация `v1.0.0` с более простым способом восстановления. Серверная конфигурация, routing и подписки не менялись. Изменён только формат хранения резервных копий в приватном GitHub Release.

## Главное изменение

Полные снимки обоих серверов приложены к private Release `v1.0.1` как обычные `.tar.gz`. Для них нет пароля и не требуется расшифрование: достаточно войти в GitHub под аккаунтом, имеющим доступ к приватному репозиторию, скачать архив и проверить SHA-256.

На момент выпуска:

- репозиторий имеет статус `PRIVATE`;
- единственный collaborator — владелец `Sanchecz`;
- незавершённых приглашений другим аккаунтам нет;
- архивы не добавлены в Git-историю, а находятся только в Release assets.

## Что сохранено без изменений

- старые ссылки Happ, UUID, `sub_id`, клиенты и назначения;
- SSH-пользователи, пароли и способ входа;
- публичные inbounds и серверные протоколы;
- обновление Happ раз в один час;
- стабильный routing без ссылок `geosite:*`/`geoip:*`;
- direct-маршрут российских доменов;
- proxy-маршрут Telegram, OpenAI и иностранных сервисов;
- отключённое состояние регрессивных healthcheck-таймеров.

## Где что находится

- `RESTORE.ru.md` — восстановление без пароля;
- `CODEX_RUNBOOK.ru.md` — правила будущей работы Codex и выпуска raw-бэкапов;
- `IF_YOU_FORGOT.ru.md` — памятка владельцу;
- `SECURITY.ru.md` — последствия выбранного хранения без шифрования;
- `VALIDATION.ru.md` — серверные и релизные проверки;
- `routing/RoscomVPN.routing.json` — текущий профиль без пользовательских секретов;
- `scripts/portable-backup.sh` — создание нового снимка;
- `scripts/audit_portable_backup.sh` — аудит скачанного архива;
- `scripts/build_happ_link.py` — воспроизведение Happ routing-ссылки;
- `scripts/verify_release.py` — проверка файлов документационного ZIP;
- `SHA256SUMS.txt` — SHA-256 отслеживаемых файлов.

Release assets будут содержать:

- `3x-ui-happ-v1.0.1-kit.zip`;
- `portable-current-main-20260813T124133Z.tar.gz`;
- `portable-current-node2-20260813T124235Z.tar.gz`;
- `SHA256SUMS-release.txt`.

## Важное предупреждение

Любой человек, получивший доступ к приватному репозиторию или скачавший один из `.tar.gz`, получит доступ к базе 3x-ui, сертификатам и приватным ключам. Поэтому нельзя делать репозиторий публичным или добавлять collaborators, пока эти assets существуют.

# Если забыл, что делать

## Где лежит всё необходимое

Войти в GitHub под аккаунтом `Sanchecz`, открыть приватный `Sanchecz/Remote-Desktop`, перейти в **Releases** и выбрать Latest `v1.0.1`.

Пароля нет. Нужны только доступ к вашему GitHub и скачанные файлы.

## Если нужно восстановить основной сервер

Скачать:

- `3x-ui-happ-v1.0.1-kit.zip`;
- `portable-current-main-20260813T124133Z.tar.gz`;
- `SHA256SUMS-release.txt`.

Затем открыть `RESTORE.ru.md`. Сначала проверить SHA и запустить audit. Старый сервер не удалять и DNS заранее не переключать.

## Если нужно восстановить второй сервер

Скачать `portable-current-node2-20260813T124235Z.tar.gz` вместо main и использовать роль `node2` при запуске audit.

## Если забыт SSH-пароль

Release не меняет SSH-пароли. Использовать менеджер паролей или recovery-консоль провайдера. Если доступа нет, сначала создать snapshot диска через панель провайдера; не переустанавливать сервер вслепую.

## Если GitHub-репозиторий случайно стал публичным

Сразу вернуть `PRIVATE`, убрать посторонних collaborators и проверить журнал доступа/скачиваний. Поскольку raw-архивы содержат секреты, при фактической публичной доступности нужно планировать ротацию сертификатов, Reality/WireGuard-ключей, токенов и данных доступа 3x-ui.

## Если Telegram снова зависает

Проверить, что оба `openai-chain-*-healthcheck.timer` остаются `inactive` и `disabled`, а routing совпадает с контрольным SHA `v1.0.1`. Не менять сразу пользователей, inbounds и ссылки подписок. Сначала снять новый backup и собрать фактические логи.

## Если Happ пишет об отсутствующей секции

Проверить, что routing содержит ноль `geosite:*`/`geoip:*` и пустые GEO URL. Стабильная версия не требует секций `TORRENT`, `TWITCH-ADS`, `WHITELIST` или `DIRECT`.

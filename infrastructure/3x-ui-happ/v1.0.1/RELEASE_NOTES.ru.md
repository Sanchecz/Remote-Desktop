# Примечания к выпуску `v1.0.1`

Дата: 13 августа 2026 года

## Назначение

`v1.0.1` — удобный переносимый выпуск без пароля по прямому указанию владельца. Он использует ту же подтверждённую стабильную серверную точку и тот же routing, что `v1.0.0`.

## Что изменено относительно `v1.0.0`

- в assets добавлены обычные переносимые `.tar.gz` обоих узлов;
- расшифрование и отдельное хранение пароля больше не требуются;
- инструкции переписаны для прямого скачивания и восстановления;
- добавлены правила для Codex: raw-архивы можно размещать только в private Release assets, но нельзя коммитить;
- добавлено обязательное предупреждение не делать репозиторий публичным и не выдавать доступ другим аккаунтам.

## Что не изменено

- содержимое серверной конфигурации;
- URL подписок и данные клиентов;
- routing и его контрольные SHA;
- DNS, TLS и SSH-доступ;
- рабочие процессы x-ui/Xray;
- состояние Telegram/Happ;
- серверные файлы и службы.

Никаких команд, изменяющих production, для этого выпуска не выполнялось.

## Рекомендуемый smoke-test после любого переноса

1. Три раза обновить подписку Happ.
2. Дважды отключить и подключить VPN без остановки Telegram.
3. Проверить сообщения, истории, файлы и статус Telegram.
4. Проверить `.ru`/`.рф`, Госуслуги/MAX и один иностранный сайт.
5. Проверить OpenAI trace и обычный trace второго узла.
6. Убедиться, что купленный сторонний профиль Happ не изменён серверной конфигурацией.

# 3x-ui + Happ — стабильный переносимый выпуск `v1.0.0`

Это зафиксированная рабочая конфигурация двух узлов 3x-ui/Xray для Happ. Выпуск подготовлен после клиентского подтверждения: Telegram подключается сразу, повторные подключения работают, а обновление подписки больше не вызывает ошибок Xray о секциях `TORRENT`, `TWITCH-ADS`, `WHITELIST` или `DIRECT`.

## Что сохранено

- все существующие URL подписок, `sub_id`, UUID, клиенты и назначения клиент → inbound;
- прежние SSH-пользователи, пароли и способ входа;
- публичные inbounds и их протоколы;
- обновление подписок Happ раз в один час;
- прямой выход для российских доменов, включая `.ru`, `.рф`, Госуслуги, MAX и российские сервисы;
- proxy-маршрут для иностранных сервисов, включая Telegram, OpenAI, Google и GitHub;
- двухузловая служебная конфигурация маршрута OpenAI;
- блокировка известных доменов BitTorrent-трекеров.

## Почему эта версия стабильнее

В routing-профиле больше нет ни одной ссылки `geosite:*` или `geoip:*` и нет внешней загрузки GEO-файлов. Все нужные правила представлены обычными доменами, регулярными выражениями и явными приватными CIDR. Поэтому запуск Xray не зависит от того, какую версию `geosite.dat` или `geoip.dat` успел загрузить Happ при первом или повторном обновлении.

Пятиминутные healthcheck-таймеры служебного OpenAI-маршрута на обоих серверах оставлены выключенными. Они изменяли рабочий runtime Xray и совпали по времени с регрессией Telegram. Конфигурация самого служебного маршрута сохранена в зашифрованных снимках, но автоматическое вмешательство в Xray не выполняется.

## Состав каталога

- `RELEASE_NOTES.ru.md` — итог работ и ограничения;
- `RESTORE.ru.md` — перенос на другой сервер без смены старых ссылок Happ;
- `CODEX_RUNBOOK.ru.md` — инструкция Codex для будущего обновления и публикации;
- `IF_YOU_FORGOT.ru.md` — короткая памятка владельцу «если забыл, что делать»;
- `SECURITY.ru.md` — обращение с секретами и зашифрованными архивами;
- `VALIDATION.ru.md` — результаты проверок стабильной точки;
- `routing/RoscomVPN.routing.json` — очищенный от пользовательских секретов routing-профиль;
- `routing/SOURCES.ru.md` — происхождение явных доменных списков;
- `scripts/portable-backup.sh` — создание полного root-only снимка сервера;
- `scripts/backup_crypto.py` — потоковое AES-256-GCM шифрование и расшифрование;
- `scripts/audit_portable_backup.sh` — аудит архива без восстановления;
- `scripts/build_happ_link.py` — сборка `happ://routing/add/...` из JSON;
- `scripts/verify_release.py` — проверка SHA-256 файлов комплекта;
- `SHA256SUMS.txt` — контрольные суммы файлов этого каталога.

Зашифрованные полные снимки `.xuibak` не лежат в Git-истории. Они приложены как assets к приватному GitHub Release `v1.0.0`, чтобы база 3x-ui, сертификаты и приватные ключи не попадали в commit.

## Быстрая проверка

Из каталога версии:

```bash
python3 scripts/verify_release.py
```

Проверка зашифрованного снимка описана в `RESTORE.ru.md`. Пароль расшифрования хранится у владельца отдельно от GitHub.

# Если забыл, что делать

## Где лежит всё необходимое

Войти в GitHub под аккаунтом владельца, открыть приватный `Sanchecz/Remote-Desktop`, перейти в **Releases** и выбрать `v1.0.2`.

Пароля у архивов нет. Защита — доступ к вашему GitHub и приватность репозитория.

## Если нужно восстановить основной сервер

Скачать:

- `3x-ui-happ-v1.0.2-kit.zip`;
- `portable-current-main-20260813T221137Z.tar.gz`;
- `SHA256SUMS-release.txt`.

Открыть `RESTORE.ru.md`. Сначала сверить SHA и запустить audit. Старый сервер не удалять, DNS заранее не переключать.

## Если нужно восстановить второй сервер

Скачать `portable-current-node2-20260813T221230Z.tar.gz` и использовать роль `node2` в audit.

## Если забыт SSH-пароль

Release не меняет и не показывает SSH-пароли в документации. Использовать свой менеджер паролей или recovery-консоль провайдера. Перед любыми действиями через recovery сделать snapshot диска; не переустанавливать сервер вслепую.

## Если Happ на iPhone снова вылетает при подписке

1. Не менять UUID, inbounds или VPN-протоколы.
2. Снять backup.
3. Проверить настройки доставки routing:

   ```text
   subRoutingRules=<пусто>
   subIncyEnableRouting=true
   subIncyRoutingRules=happ://routing/add/...
   ```

4. Проверить deeplink SHA `46f76e0a81e24d28e8f7bb492baeaab4779cda71adf8436b0d9b95f63fb4976b`.
5. Проверить отсутствие регистрозависимых дублей и boolean-полей.
6. Временно убрать routing можно только как диагностический тест; отсутствие routing не является готовым постоянным решением.

## Если Telegram снова висит в «Соединение»

- убедиться, что server-side sniffing на публичных inbounds остаётся выключен;
- убедиться, что оба автоматических `openai-chain-*-healthcheck.timer` выключены;
- не выполнять широкие перезапуски;
- снять логи и backup до изменения;
- проверить Telegram DC через каждый профиль и затем телефон: сообщения, истории, файлы, статус, повторное подключение.

## Если Happ пишет про отсутствующую GEO-секцию

Стабильный routing содержит 0 `geosite:*`/`geoip:*` и пустые `Geoipurl`/`Geositeurl`. Не добавлять по одной отсутствующие секции. Восстановить канонический профиль из `v1.0.2` и проверить его валидатором.

## Если OpenAI снова показывает неверный регион

- основной узел должен показывать немецкий выход;
- второй узел должен направлять только OpenAI через служебный канал на основной;
- запустить healthcheck вручную, не включать таймер;
- не включать публичный sniffing ради OpenAI: ранее он ломал Telegram.

## Если репозиторий случайно стал публичным

Сразу вернуть `PRIVATE`, закрыть доступ посторонним, проверить invitations/collaborators и журнал скачиваний. Raw-архивы содержат ключи и данные 3x-ui; если они реально были доступны посторонним, планировать ротацию секретов после сохранения рабочего backup и оценки последствий.

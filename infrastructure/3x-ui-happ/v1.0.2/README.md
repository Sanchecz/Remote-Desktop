# 3x-ui + Happ — стабильный переносимый выпуск `v1.0.2`

`v1.0.2` фиксирует подтверждённую на iPhone стабильную точку двух серверов 3x-ui/Xray. Старые ссылки подписок, UUID, `sub_id`, inbounds, SSH-доступ и серверные протоколы сохранены. Автообновление Happ остаётся раз в один час.

Главное изменение — исправлена авария Happ на iOS при импорте или обновлении полной подписки. Причиной был не набор VPN-узлов, а неканонический routing JSON: регистрозависимые дубли ключей, устаревшее написание полей и несовместимые JSON-типы. Исправленный профиль успешно загружается на iPhone вместе с полной подпиской.

## Подтверждённое рабочее состояние

- 10 действующих `sub_id` отвечают HTTP `200`;
- сохранены 10 клиентов и 113 назначений клиент → inbound;
- все старые URL подписок продолжают работать;
- routing доставляется строкой `happ://routing/add/...` внутри тела подписки;
- большой HTTP-заголовок `Routing` больше не используется;
- `Routing-Enable: true` и `Profile-Update-Interval: 1` сохранены;
- Xray проходит `Configuration OK`;
- Telegram ранее подтверждён как рабочий без обязательной остановки приложения;
- iPhone подтвердил обновление полной подписки с исправленным routing без вылета Happ;
- OpenAI на втором узле выходит через основной немецкий узел;
- регрессивные автоматические healthcheck-таймеры остаются `inactive` и `disabled`.

## Исправление iOS routing

В старом профиле одновременно присутствовали:

- `GeoipUrl` и `Geoipurl`;
- `GeositeUrl` и `Geositeurl`;
- `RemoteDNSIp` вместо `RemoteDNSIP`;
- `DomesticDNSIp` вместо `DomesticDNSIP`;
- `FakeDns` вместо `FakeDNS`;
- JSON-boolean для `GlobalProxy`, `FakeDNS` и `UseChunkFiles` вместо строковых значений Happ.

В `v1.0.2`:

- 22 ключа верхнего уровня уникальны без учёта регистра;
- используются канонические имена полей Happ;
- `GlobalProxy`, `FakeDNS`, `UseChunkFiles` имеют строковые значения `"true"`/`"false"`;
- все 469 direct, 18 proxy, 431 block и 11 private-IP правил сохранены;
- отсутствуют `geosite:*` и `geoip:*`;
- `Geoipurl` и `Geositeurl` пустые;
- ошибки отсутствующих секций `TORRENT`, `TWITCH-ADS`, `WHITELIST`, `DIRECT` не должны возникать.

## Маршрутизация

- российские `.ru`, `.su`, `.рф`, Госуслуги, MAX, банки, магазины и локальные сервисы идут напрямую;
- Telegram, OpenAI, ChatGPT и иностранные сервисы идут через выбранный VPN-профиль;
- неизвестный не-RU трафик по умолчанию идёт через VPN (`GlobalProxy = "true"`);
- известные torrent/DHT/tracker-домены блокируются 431 явным правилом;
- серверный sniffing намеренно не включён: он уже вызывал регрессию Telegram;
- блокировка torrent является доменной защитой, а не полной DPI-гарантией для зашифрованного BitTorrent по голому IP.

## Критически важно

Raw-архивы содержат базу 3x-ui, пользовательские UUID/`sub_id`, сертификаты, приватные ключи и служебную конфигурацию. Доступ к private Release фактически равен доступу к этим секретам. Репозиторий нельзя делать публичным, пока assets существуют; не добавляйте collaborators без осознанного предоставления им полного доступа.

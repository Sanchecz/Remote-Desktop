# RemoteIt 1.0.31

- Экранный helper сохраняет системные права, необходимые драйверам Windows Server для DXGI, но его primary token жёстко переводится только в SID-привязанный RDP/VDI session ID.
- Сочетание системного токена и выбора точного DXGI-выхода устраняет `E_ACCESSDENIED` на многодисплейном GEN-HV без перехода в сеанс другого пользователя.
- Сохранена точная нефатальная диагностика VDI из 1.0.30; она автоматически исчезает после первого успешного кадра.

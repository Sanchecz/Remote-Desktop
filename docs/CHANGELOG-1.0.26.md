# RemoteIt 1.0.26

## Файлы

- файловый менеджер переделан в двухпанельный проводник: слева выбранные файлы администратора, справа файловая система удалённого компьютера;
- файлы можно перетаскивать с устройства администратора на удалённый компьютер и с удалённого компьютера в локальные загрузки;
- локальный файл можно бросить прямо на строку нужной удалённой папки;
- добавлены очередь выбранных файлов, понятный прогресс, скорость, оставшееся время и отмена;
- Agent получает новый transfer немедленно через долгий запрос вместо задержки старого трёхсекундного опроса; стартовая часть 8 МиБ быстро запускает приём, последующие части до 64 МиБ снижают число сетевых и дисковых round-trip.

## Удалённый экран

- явный режим 60 FPS сохраняет разрешение до 2560 пикселей, JPEG quality 90 и цвет 4:4:4; автоматический 60 FPS по-прежнему использует ограниченный профиль для слабых каналов;
- планировщик кадра больше не пытается компенсировать задержанный кадр слишком ранним следующим кадром, поэтому 15/30/60 FPS идут ровнее;
- горизонтальный телефон всегда показывает компактные полупрозрачные кнопки прокрутки вверх/вниз, поддерживающие удержание;
- существующее портретное управление и desktop-компоновка не изменены.

## Android Agent пользователя

- добавлено отдельное приложение `RemoteIt-Agent-Android.apk`, которое регистрирует телефон по обычному ограниченному токену и получает собственный Remote ID;
- токен копируется при скачивании из панели и автоматически подставляется из буфера при первом запуске Agent;
- экран передаётся только после видимого системного подтверждения Android, а управление включается владельцем телефона в системной службе специальных возможностей;
- панель разрешает удалённый экран для Windows и Android, но не показывает Android-команды Windows, которые телефон не поддерживает.

## Проверки

- Go test для Agent, Server и MCP;
- полная Web unit-матрица, TypeScript и production Vite build;
- Android debug build, Lint и release build обоих APK с проверкой v2/v3-подписи;
- визуальная проверка файлового проводника на desktop, 390×844 и 844×390 без горизонтального переполнения.

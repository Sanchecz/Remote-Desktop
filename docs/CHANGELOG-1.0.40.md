# RemoteIt 1.0.40

## RDP и SSH в браузере

- RDP и SSH открываются через HTML5-шлюз Apache Guacamole без установки RemoteIt Console на компьютер администратора.
- Agent выбранного пользователя остаётся фоновым сетевым мостом к частному IP. На шлюзовом компьютере не запускаются `mstsc`, консоль или браузер.
- `guacd` доступен только во внутренней Docker-сети. Внутренние RDP/SSH-порты не публикуются в интернет и не требуют VPN.
- Пароль не записывается в PostgreSQL и защищённый журнал. Он входит только в короткоживущий подписанный и зашифрованный JSON-сеанс Guacamole.
- Факт подключения, администратор, Agent, внутренний IP и порт сохраняются в защищённом аудите.

## Мониторинг

- Добавлен отдельный раздел «Мониторинг» над настройками.
- Для компьютеров отображаются онлайн-статус, CPU, RAM, свободное место, версия Agent, права службы и последняя ошибка удалённого экрана. Эти состояния рассчитываются на сервере одинаково для web-клиентов и сохраняются как отдельная история Windows/Linux/macOS-узлов.
- Сетевые цели проверяются через выбранный Agent. Есть профили MikroTik, универсального роутера, Windows/RDP, Linux/SSH и принтера/МФУ.
- Для портов можно выбрать политику: достаточно хотя бы одного отвечающего сервиса (удобно для роутеров и МФУ) либо обязательны все указанные порты. Задержка считается по реально ответившему сервису.
- Проверки ограничены частными IPv4-адресами и максимум 16 явно указанными TCP-портами.
- История и проблемные измерения хранятся отдельно от защищённого аудита. Поддерживаются сроки 1, 7, 30, 90 дней или без автоудаления.
- Ручная очистка удаляет только историю мониторинга; устройства, цели, настройки и аудит сохраняются.
- Изменение состояния компьютера пишется сразу, а стабильное состояние — не чаще одного раза в 30 минут. В панели показаны суммарные число измерений, проблемных записей и фактический размер мониторинговых таблиц на VDS.

## Сеть и принтеры

- Сканер внутренних IP вынесен из настроек в отдельный раздел и группирует Agent по вошедшему пользователю.
- Автовыбор сети предпочитает физический Ethernet/Wi-Fi и понижает приоритет WireGuard, VPN, Hyper-V, WSL, Docker, Tailscale и других виртуальных интерфейсов.
- Результат показывает все найденные локальные подсети и рекомендуемый интерфейс.
- Для найденных узлов проверяется ограниченный набор типовых административных, RDP/SSH, печатных и MikroTik-портов.
- Поиск принтеров использует тот же корректный выбор LAN и увеличенный сетевой таймаут для медленных МФУ.

## Безопасность и эксплуатация

- Фоновые проверки не показывают пользователю технические окна, но создание целей, изменение хранения, очистка истории и подключения аудитируются.
- Значение `REMOTEIT_GUACAMOLE_JSON_SECRET` хранится только в серверном `.env`; служебные URL Guacamole исключены из access-log Caddy, чтобы зашифрованный сеанс не оставался в журнале прокси.
- Обычные Guacamole-подключения не пишут внутренние IP и имена сеансов в Docker-лог: собственный `logback.xml` web-шлюза и уровень `warning` у `guacd` оставляют только предупреждения и ошибки; логи ограничены ротацией Compose.
- Версии Windows Agent, Console (для обратной совместимости), MCP, Android-приложений, PWA и метаданных синхронизированы как `1.0.40`.

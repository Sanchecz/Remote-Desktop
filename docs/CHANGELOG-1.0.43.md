# RemoteIt 1.0.43

## Исправлено

- Встроенные RDP- и SSH-сеансы снова разрешены внутри защищённой панели RemoteIt; остальная часть сайта по-прежнему запрещает встраивание во внешние страницы.
- RDP запускается с 24-битным цветом, динамическим разрешением, GFX и рабочими кэшами Guacamole без принудительного lossless-режима, который увеличивал бы задержку.
- Файловый менеджер переделан в компактный двухпанельный интерфейс «моё устройство ↔ удалённый компьютер» с понятной отправкой, загрузкой и состояниями пустых папок.
- Форма сетевого сканера выровнена, а Windows Agent дополняет найденные адреса именами через обратный DNS и ограниченный NetBIOS fallback.
- Для найденных сетевых принтеров явно показано наличие веб-панели и действие открытия её на удалённом компьютере.

## Совместимость и выпуск

- Версии Windows Agent/Console/MCP, macOS/Linux Agent, Web/PWA и двух Android APK синхронизированы как 1.0.43.
- Android versionCode повышен до 130 для клиентского приложения и до 18 для мобильного Agent.

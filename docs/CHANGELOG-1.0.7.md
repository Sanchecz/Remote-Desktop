# RemoteIt 1.0.7

## Защищённые экраны Windows

- Agent освобождает DXGI/GDI-ресурсы до переключения потока захвата между пользовательским и защищённым рабочими столами Windows.
- Экран входа, Windows Security, CredUI и UAC снимаются свежим GDI-кадром; устаревшая текстура пользовательского рабочего стола больше не остаётся в просмотре.
- Если защищённый экран статичен, Agent отправляет контрольный кадр каждые 5 секунд. Сервер не считает живое изображение устаревшим после своего 15-секундного лимита.
- После разблокировки или закрытия окна учётных данных Agent немедленно пересоздаёт DXGI-захват и возвращается к ускоренному режиму.

## Безопасность

- Изменения не отключают Secure Desktop, UAC, Windows Security, NLA или запрос учётных данных RDP.
- Пассивный предпросмотр остаётся без управления; мышь и клавиатура включаются только после явного начала управляющего сеанса.

## Проверки релиза

- unit-тесты распознавания обычного и защищённого рабочих столов;
- unit-тест пятисекундного контрольного кадра;
- полный набор Go-тестов Agent и Windows amd64-компиляция тестового binary;
- production-сборки Web, Server, Windows/Linux/macOS Agent и подписанного Android APK.

# RemoteIt 1.0.42

Корректирующий production-релиз после полного живого acceptance-теста 1.0.41.

- Исправлена доставка подписанных действий: аудируемый `action_jobs.id` больше не сравнивается с отдельным транспортным `agent_jobs.id`; внешний идентификатор сверяется с подписанным конвертом, а защита подписью, сроком и одноразовым nonce сохранена.
- Исправлено чтение Action Job из Web-панели: пустая строка больше не передаётся PostgreSQL как UUID для owner/admin-запросов.
- На двух реальных Windows VDI-узлах подтверждён отдельный headless-путь: Agent находит RDP даже без ответа ICMP, открывает `TCP/3389`, а встроенный Guacamole-сеанс переходит в `connected` без DXGI/GDI-захвата и физического монитора. Проверка повторена несколькими независимыми циклами.
- Сохранены изменения 1.0.41: несколько CIDR/IP-диапазонов за один скан, поиск RDP/SSH даже при заблокированном ICMP, встроенные браузерные RDP/SSH, компактный двусторонний файловый менеджер, прокручиваемая навигация и защита буфера от устаревших подтверждений.
- Версии Windows Agent/Console/MCP, macOS/Linux Agent, Web/PWA и двух Android APK синхронизированы как 1.0.42.

# RemoteIt 1.0.33

## Мобильный полноэкранный режим

- В портретном полноэкранном режиме телефон показывает весь рабочий стол Windows целиком: края больше не обрезаются принудительным режимом `Заполнить`.
- Горизонтальный телефон сохраняет отдельный режим заполнения, а десктопный клиент — прежнее поведение.

## Общий буфер обмена

- Текст и изображения теперь проходят через одну упорядоченную очередь: поздний ответ больше не может затереть более новые данные другого типа.
- Windows Agent сообщает номер поколения системного буфера. После `Cmd+C`/`Ctrl+C` клиент дожидается именно нового значения, что особенно важно на медленном VDI.
- Чтение и запись Windows Clipboard повторяются при кратковременной блокировке буфера другой программой.
- Изображения браузера нормализуются в PNG; если расширенное чтение браузера запрещено, сохраняется безопасный текстовый fallback.
- Кнопка больше не выглядит как непонятный переключатель «Буфер общий». Автоматическая синхронизация включена постоянно, а явное действие показывает одно из состояний: `Синхронизировать буфер`, `Получить с удалённого ПК`, `Синхронизация…`, `Повторить`.

## Совместимость и безопасность VDI

- Привязка экрана к конкретному Windows SID и запрет перехода к другому пользователю сохранены.
- Постоянный кадр полностью отключённого RDS-сеанса требует виртуального дисплея на VDI-хосте. Пароль пользователя не сохраняется и сеанс не подключается к чужой WinStation: такой обход может показать экран другого пользователя или вытеснить его подключение.

# RemoteIt 1.0.41

## Сеть и встроенные подключения

- Сканер принимает до восьми значений за один запуск: CIDR-подсети, отдельные внутренние IPv4-адреса и диапазоны `IP-IP`, разделённые запятой, точкой с запятой или новой строкой.
- Диапазоны могут пересекать границу подсети; повторяющиеся адреса исключаются. Общий жёсткий предел — 1024 уникальных внутренних адреса.
- Windows Agent ищет узлы не только по ICMP/ARP, но и по фиксированному безопасному набору портов RDP, SSH, файловых, веб- и печатных служб. Это позволяет обнаружить компьютеры, которые не отвечают на ping.
- Проверки выполняются с ограниченной параллельностью; лимит времени задания увеличен для двух и более подсетей.
- RDP и SSH больше не зависят от всплывающего окна браузера: HTML5-сеанс открывается непосредственно внутри панели RemoteIt, поддерживает переподключение, полноэкранный режим, закрытие и резервное открытие во вкладке.

## Файлы, навигация и буфер обмена

- Файловый менеджер уплотнён и оформлен как две понятные стороны: выбранные файлы этого устройства слева и удалённая файловая система справа.
- Направления передачи, выбор файлов, загрузка в открытую папку и скачивание из строки файла обозначены явно; сохранены потоковая передача, возобновление, отмена и предел 50 ГБ на файл.
- Левая панель получила независимую вертикальную прокрутку и компактный режим для небольших по высоте экранов; нижние элементы аккаунта больше не вытесняют пункты меню.
- Устранена гонка двустороннего буфера: запоздавший ответ с более старой системной ревизией Windows больше не может заменить актуальный текст. Учтено переполнение 32-битного счётчика Windows.

## Совместимость и выпуск

- Версии Windows/macOS/Linux Agent, совместимой Console, MCP, веб-приложения, PWA и двух Android-приложений синхронизированы как `1.0.41`.
- Android Viewer: `versionCode 128`; Android Agent: `versionCode 16`.
- Пароли RDP/SSH остаются только в короткоживущем зашифрованном описании Guacamole-сеанса и не добавляются в БД, журнал или релизные артефакты.

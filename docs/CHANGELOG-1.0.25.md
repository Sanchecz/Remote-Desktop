# RemoteIt 1.0.25

## Удалённый экран и полноэкранный режим

- вместо неоднозначных процентов добавлены три предсказуемых режима: «Весь экран», «Заполнить» и «1:1»;
- полноэкранный режим на ПК скрывает крупные панели, заполняет монитор удалённым кадром и оставляет компактные полупрозрачные команды;
- телефон в полноэкранном режиме использует заполнение без тёмных полос, сохраняя пропорции и доступ к обрезанным краям через панорамирование;
- текущий декодированный кадр можно скопировать как PNG в локальный буфер; при ограничении браузера он скачивается без потери исходного разрешения;
- задержка распознавания первого движения мобильного курсора сокращена с 34 до 18 мс без изменения качества JPEG.

## Общий буфер

- кнопка «Общий буфер» включает двустороннюю синхронизацию текста на время удалённого сеанса;
- изменения на локальном и удалённом компьютере передаются без повторного ручного нажатия «Вставить»;
- системные ограничения браузера показываются явно; объекты и большие данные предлагается передавать через защищённый файловый канал.

## VDI и RDP

- при переподключении RDP, смене VDI-сеанса или переходе на защищённый рабочий стол устаревшие GDI/DC-ресурсы освобождаются и создаются заново;
- неудавшийся GDI-кадр повторяется в том же цикле, поэтому исправимая ошибка больше не оставляет активный Agent в постоянном состоянии «не удалось скопировать экран»;
- при повторной реальной ошибке ресурсы также освобождаются, чтобы следующий цикл мог восстановить захват.

## Проверки релиза

- полная Web unit-матрица, TypeScript и production Vite build;
- отдельные проверки режимов fit/fill для портретных, горизонтальных, стандартных и нестандартных разрешений;
- Go tests/vet и Windows-сборка Agent/Server в release-контейнере;
- Android unit/lint/release build и проверка production-подписи APK.

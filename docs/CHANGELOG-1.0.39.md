# RemoteIt 1.0.39

## Android Agent пользователя

- Экран подготовки доступа перестроен в два последовательных шага: сначала `Accessibility` для управления, затем `MediaProjection` для показа всего экрана.
- Перед системными окнами показана короткая инструкция; после возврата из настроек статус и доступность следующей кнопки обновляются автоматически.
- Используется официальный раздел специальных возможностей Android, а подсказка называет нужный промежуточный пункт для Samsung, Xiaomi/Redmi/POCO, Huawei/Honor и стандартного Android.
- Нельзя случайно запустить просмотр без управления: разрешение повторно проверяется после системного окна, а при его последующем отключении трансляция останавливается. Активный доступ явно виден в приложении и постоянном уведомлении и останавливается одной кнопкой.
- `compileSdk` и `targetSdk` обновлены до 37, добавлены правила запрета резервного копирования регистрационных данных и unit-тест всех состояний разрешений.
- Поворот телефона больше не сбрасывает введённый токен, адрес, имя устройства или промежуточный шаг между разрешением уведомления и выбором показа экрана.
- На Android 14+ системный запрос ограничен показом всего дисплея: пользователю больше не нужно разбираться в выборе между отдельным приложением и полным экраном; Android 8–13 используют совместимый штатный запрос.

## RDP и SSH без VPN

- RDP и SSH вынесены из карточки устройства в отдельный раздел панели для владельца и администраторов.
- Панель создаёт одноразовый двухсторонний WSS-туннель: Agent соединяется только с внутренним IPv4, а RemoteIt Console поднимает локальный `127.0.0.1`-порт и открывает штатный `mstsc` или `ssh` на компьютере администратора.
- Публичные, loopback, multicast и некорректные адреса отклоняются сервером и повторно проверяются Agent. Пароль не попадает в API, задания, БД или аудит.
- Ключ клиентской стороны передаётся серверу в заголовке, однократно резервируется в БД и не попадает в URL reverse proxy. Разрывы до сопряжения и ошибки Agent переводят туннель в конечное состояние.
- Одному администратору разрешено не более восьми одновременных туннелей; истёкшие соединения закрываются, а их служебные записи удаляются через семь дней.
- RemoteIt Console один раз устанавливает себя в локальный профиль администратора, регистрирует `remoteit://` без прав администратора и удаляет заменённые версии при следующем успешном запуске.

## Файлы, сеть и принтеры

- Лимит потоковой возобновляемой передачи увеличен до 50 ГиБ во всех слоях: браузер, API, БД и Agent; контрольная точка проверена на полном диапазоне 50 ГиБ без небезопасной арифметики.
- Перетаскивание на удалённый экран предлагает точное назначение: Рабочий стол, Загрузки или Документы; тот же выбор доступен для файлов из буфера.
- Принтеры получили отдельный раздел: локальные очереди, поиск стандартных IPP/JetDirect/LPD-служб не более чем в одной внутренней `/24`-подсети, переход к веб-интерфейсу и штатным параметрам Windows.
- Универсальный сканер внутренних IP оставлен отдельным диагностическим инструментом в настройках.

## macOS и интерфейс

- Для каждого установочного токена формируется готовый `RemoteIt Agent.app` в ZIP с универсальным Intel/Apple Silicon launcher, встроенным токеном и штатным запросом прав для LaunchDaemon.
- Защищённые устройства не исчезают из новых разделов: перед RDP/SSH или работой с принтерами панель показывает явную карточку разблокировки.
- Версии Windows Agent, Console, MCP, Android приложений, PWA и метаданных загрузки синхронизированы как `1.0.39`.
- Release-сборка проверяет подпись обоих APK, требует один и тот же сертификат и сама формирует публичный `APK-SIGNER.txt` до расчёта `SHA256SUMS.txt`.

## Проверки

- Go unit-тесты Agent, Console, server и MCP; отдельные проверки URL/параметров туннеля и частных IPv4.
- 95 web unit-тестов: клавиатура, камера/масштаб, кадры, курсор, ввод, viewport и поворот, reconnect, файлы до 50 ГиБ, двусторонний буфер и настройка Codex.
- TypeScript production build, Android Agent unit/lint/debug build и Windows cross-build RemoteIt Console.

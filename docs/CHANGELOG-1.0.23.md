# RemoteIt 1.0.23

## Удалённый доступ

- шесть независимых линий кадров и отдельный подтверждаемый канал управления уменьшают задержку без накопления старых кадров;
- Auto начинает с 30 FPS, повышает частоту только на устойчивом канале и сохраняет детальность текста на 2K/4K экранах;
- молча зависший WebSocket автоматически заменяется HTTP-потоком и переподключается без закрытия сеанса;
- мышь, клавиатура, AltGr, Enter, Backspace/Delete и Ctrl+Alt+Delete сохраняют порядок и защищены от повторного выполнения после потери ответа.

## Телефон и браузеры

- режимы «Курсор» и «Касание», точное масштабирование в точку жеста и автопрокрутка у границы удалённого экрана;
- устойчивое переключение портрет/ландшафт, полноэкранный режим и сохранение клавиатуры при изменении Visual Viewport;
- безопасный Pointer Capture для Android WebView, Chrome, Edge, Firefox и Safari: отказ браузера больше не обрывает жест;
- мобильная клавиатура передаёт текст в реальном времени и удаляет уже существующий удалённый текст.

## Передача файлов и устойчивость

- потоковые файлы до 10 ГБ с быстрым первым блоком, крупными последовательными блоками, продолжением и отменой;
- сервер сериализует повторные блоки одного transfer ID, Agent отклоняет небезопасные идентификаторы до обращения к временному пути;
- ввод старого завершённого сеанса не может попасть в очередь нового устройства;
- Windows Agent восстанавливает IP и соединение после смены Wi-Fi, VPN и выхода из сна.

## Проверки релиза

- 83 web unit-теста, TypeScript и production Vite build;
- повторные Go-тесты и `go vet` для Server, Agent и MCP;
- Android clean/unit/lint/debug и обязательная проверка production-подписи APK;
- Windows/Linux/macOS/arm64 кросс-сборки, SHA-256 артефактов, healthcheck и проверяемый откат.

# RemoteIt 1.0.4

## Удалённый доступ на Android

- Экранная клавиатура вызывается отдельной компактной кнопкой и больше не открывает поверх рабочего стола большую панель инструментов.
- Поле ввода работает как живой мост: символы, кириллица, удаление и замена автокоррекцией передаются на удалённый компьютер сразу, без обязательного нажатия `Enter`.
- `Enter` остаётся самостоятельной кнопкой и отправляется как реальная клавиша; закрытие локальной клавиатуры не удаляет уже введённый текст на удалённом компьютере.
- При открытой клавиатуре камера не пересчитывается по временно уменьшенной Android-клавиатурой области, поэтому экран не прыгает и не меняет масштаб.
- В портретной и альбомной ориентации строка ввода остаётся тонкой плавающей панелью и освобождает максимум места для удалённого экрана.

## Жесты и управление

- Увеличение двумя пальцами сохраняет точку под пальцами, включая портретный режим с полями вокруг широкоформатного экрана.
- Режим «Курсор» различает pinch-масштабирование и прокрутку двумя пальцами; короткое касание двумя пальцами выполняет правый клик.
- Долгое касание в режиме «Курсор» выполняет правый клик, а двойное касание с удержанием позволяет перетаскивать окна.
- Двойное касание больше не сбрасывает масштаб и корректно доходит до удалённой системы.
- В расширенной панели добавлен явный возврат масштаба «По размеру».

## Проверки

- Добавлены модульные проверки привязки pinch-жеста, границ панорамирования, портретного letterboxing и классификации мобильных жестов.
- Проверены посимвольный ввод без `Enter`, исправления Android IME, Backspace и Unicode без разрыва составных символов.
- Сохранены проверки клавиатуры для кириллицы, модификаторов, служебных и цифровых клавиш.

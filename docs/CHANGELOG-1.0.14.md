# RemoteIt 1.0.14

## Исправления мобильного удалённого доступа

- grid-контейнер активного сеанса на телефоне теперь жёстко ограничен шириной viewport и больше не расширяется из-за панели действий;
- живой экран в вертикальной и горизонтальной ориентации получает всю доступную область без скрытых 14 пикселей и показывает полный кадр с сохранением пропорций;
- letterbox остаётся активной зоной управления, а смена ориентации повторно пересчитывает fit-геометрию;
- версия Agent, Android APK, MCP-моста, PWA и release manifest синхронизирована как `1.0.14`.

# RemoteIt 1.0.2

## Управление с Android

- Масштабирование двумя пальцами привязано к точке между пальцами: выбранная область больше не перескакивает в центр экрана.
- Обновление масштаба и панорамирования синхронизировано с кадрами интерфейса, что убирает визуальные рывки при жесте.
- Панель управления стала плавающей шторкой и полностью скрывается до компактной кнопки «Управление».
- В альбомной ориентации панель больше не уменьшает удалённый экран и открывается поверх него.
- Режим «Курсор» получил локальный указатель с немедленным откликом; режим «Касание» не рисует лишний курсор.
- Длительное нажатие в режиме курсора выполняет правый клик; стабильный жест двумя пальцами прокручивает содержимое.

## Мобильная клавиатура

- Клавиатура открывается только по явному нажатию пользователя.
- Клавиша Enter на системной клавиатуре отправляет введённый текст и Enter на удалённый компьютер.
- Добавлены отдельные действия «Ввести», «Enter» и закрытие клавиатуры без потери удалённого сеанса.
- Поле использует безопасный мобильный размер шрифта и не вызывает масштабирование страницы.

## Android-оболочка

- Исправлено размещение интерфейса относительно системных панелей и вырезов экрана.
- Добавлен штатный вызов скрытия системной клавиатуры из веб-интерфейса.
- В альбомном удалённом сеансе сохраняется полноэкранный режим с корректным пересчётом рабочей области после поворота.

## Проверки

- Добавлены детерминированные тесты сохранения точки pinch-жеста, масштабирования вне центра и границ панорамирования.
- Сохранены тесты клавиатуры, Unicode, модификаторов и сочетаний клавиш.

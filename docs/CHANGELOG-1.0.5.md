# RemoteIt 1.0.5

## Исправлено

- `Ctrl+Alt+Delete` теперь выполняется настоящей системной службой Windows, а не дочерним модулем захвата экрана.
- Команда направляется в конкретный интерактивный сеанс Windows через отдельный служебный канал с подтверждением результата.
- На время системного вызова Agent безопасно включает только необходимое разрешение `SoftwareSASGeneration`, сохраняет существующую политику специальных возможностей и восстанавливает исходное значение после запроса.
- Если системная установка, служба или защищённый канал недоступны, Agent возвращает явную ошибку вместо ложного успешного результата.

## Проверки

- unit-тесты всех допустимых состояний политики `SoftwareSASGeneration`;
- unit-тест имени изолированного канала для пользовательского сеанса;
- полная Windows amd64-компиляция Agent и Windows test binary;
- тесты Agent и Server;
- проверка TypeScript и production-сборки Web;
- release-сборка Android APK.

## Ограничение Windows

`Ctrl+Alt+Delete` доступен только у Agent, установленного как системная служба. Пользовательская установка без административных прав не может формировать Secure Attention Sequence — это ограничение безопасности Windows.

# RemoteIt 1.0.6

## Безопасность VDI и RDS

- Один Remote ID теперь жёстко привязан к одному Windows SID, а не к временному номеру сеанса.
- Agent запускает трей и модуль удалённого экрана только в закреплённом пользовательском сеансе.
- Переход к другому пользователю запрещён: если закреплённый сеанс отсутствует, экран становится недоступен и чужие кадры не публикуются.
- Для одного пользователя сохраняется его отключённый, но ещё существующий VDI-сеанс; активный сеанс другого пользователя больше не перехватывается.
- При неоднозначном обновлении старого Agent все оставшиеся интерактивные модули завершаются по принципу fail closed.
- После смены версии сервер завершает старый просмотр и удаляет последний JPEG-кадр, чтобы кадр старого модуля не оставался в панели.

## Ctrl+Alt+Delete

- Канал Secure Attention Sequence создаётся только для закреплённого Windows-сеанса.
- Системная служба получает токен именно этого сеанса и выполняет `SendSAS` в его контексте.
- Команда не перенаправляется в консоль или сеанс другого VDI-пользователя.

## Установка и обновление

- Новая установка запоминает SID пользователя до запроса UAC, поэтому повышение прав не заменяет владельца на `LocalSystem`.
- Повторная установка из нужного Windows-сеанса сохраняет Remote ID и имя устройства, но безопасно меняет владельца экрана.
- Старому Agent на многопользовательском VDI после автоматического обновления требуется один раз повторно запустить установщик из целевого пользователя. Это явная миграция приватности: автоматический выбор среди нескольких пользователей запрещён.

## Проверки релиза

- unit-тесты выбора активного, подключённого и отключённого сеанса одного SID;
- тест запрета fallback на другого пользователя;
- тест отказа при неоднозначном legacy VDI;
- тест сохранения привязки при параллельной записи конфигурации;
- Windows amd64-компиляция Agent и Windows test binary;
- тесты Agent и Server, TypeScript production-сборка Web и release-сборка Android APK.

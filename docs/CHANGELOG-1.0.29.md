# RemoteIt 1.0.29

- Захват RDP/VDI теперь перебирает все DXGI-адаптеры и выбирает выход, который действительно соответствует экрану закреплённого Windows-сеанса. Это устраняет выбор физического Matrox/Hyper-V адаптера вместо Microsoft Remote Display Adapter на многопользовательских хостах.
- Отключённый RDS-сеанс больше не отвергается только потому, что Windows временно не предоставляет `OpenInputDesktop`: модуль остаётся на собственном `winsta0\\default` и ждёт восстановления поверхности, не переходя в сеанс другого пользователя.
- Сохранены общий двусторонний буфер, Cmd+C/Cmd+V для macOS и загрузка файлов перетаскиванием прямо на удалённый рабочий стол из 1.0.28.

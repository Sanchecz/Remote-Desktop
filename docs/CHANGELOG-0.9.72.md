# RemoteIt 0.9.72

## Что изменилось

- Полностью переработан интерфейс Windows Agent: фиксированная композиция, единая бело-зелёная палитра, аккуратная боковая навигация, карточки устройства и подключения, полезные быстрые действия, состояние системы и недавняя активность.
- Пиктограммы состояния и галочки больше не зависят от подстановки системных символов и одинаково выглядят на Windows 10, Windows 11 и Windows Server.
- Окно Agent сохраняет пропорции референса при системном DPI и не допускает ручного растягивания, которое раньше ломало сетку.
- Улучшены профили удалённого экрана: автоматическая адаптация FPS и качества, более быстрый выход из перегрузки, разные профили для 15/30/60 FPS, 1080p/2K/4K и интерактивного ввода.
- Исправлено переключение между удалёнными устройствами, состояние свёрнутого предпросмотра и видимость локального курсора для настольного и мобильного режимов.
- Обновлена мобильная сборка Android и номер опубликованного Agent во всех каналах обновления.
- Unix-установщик нормализуется в LF и проходит `sh -n`, поэтому установка Linux не зависит от окончания строк в исходном checkout.

## Проверки выпуска

- `go vet` и `go test` для Agent и Server;
- производственная сборка Web через TypeScript/Vite;
- release-сборка и проверка подписи Android APK;
- сборка Windows Agent с встраиваемыми иконкой, manifest и версией 0.9.72.0;
- сборка Linux amd64 и macOS Intel/Apple Silicon;
- проверка всех опубликованных файлов по `SHA256SUMS.txt`;
- синтаксическая проверка Linux/macOS установщика;
- визуальный запуск опубликованного Windows EXE в физическом окне 1450×1085;
- проверка публичного health endpoint после публикации.

## Обновление и перенос

Agent получает сведения о новой версии через `AGENT-RELEASE.json`. Для полного переноса на другой VDS используйте исходный архив выпуска вместе с инструкцией [MIGRATION.md](MIGRATION.md). Рабочая база, закрытая конфигурация и данные передач переносятся отдельным защищённым state-архивом и не публикуются в GitHub Release.

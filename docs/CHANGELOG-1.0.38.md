# RemoteIt 1.0.38

## Надёжное обновление Windows Agent

- Перед заменой установленного EXE создаётся точная локальная rollback-копия с проверкой размера и SHA-256.
- Новая версия считается установленной только после запуска EXE, проверки версии, состояния службы и PID именно из установленного пути.
- При ошибке установки или локальной проверки предыдущий Agent восстанавливается и запускается автоматически.
- Rollback-копия сохраняет привязанный установочный payload побайтно, а обычная установка по-прежнему удаляет одноразовый токен из рабочего EXE.

## Удалённое управление

- Подтверждение Ctrl+Alt+Delete теперь сообщает точный Windows-сеанс и честно означает передачу команды системной службой, не выдавая недоступную Windows проверку отрисовки защищённого экрана за выполненную.
- Сохранены SID-привязка многопользовательского VDI, восстановление DXGI/GDI после RDP-переподключения, режимы «Курсор» и «Касание», точное масштабирование, автоматический reconnect и двусторонний буфер.
- Сохранены потоковые возобновляемые передачи до 10 ГБ, загрузка файлов на рабочий стол перетаскиванием, RDP/SSH к внутренним узлам, LAN-диагностика и управление принтерами.
- RDP/SSH-задания теперь отклоняют публичный IP и на сервере, и в Agent; DNS-имя повторно разрешается в адреса внутренней сети на самом устройстве.

## Интерфейс

- Низкий landscape-экран входа теперь прокручивается целиком и не скрывает нижние действия за границей visual viewport.
- Мобильное управление сохраняет полноэкранную кнопку только при свёрнутой шапке, поэтому она не перекрывает завершение сеанса.

## Ограничение VDI

- RemoteIt не переключается на чужой SID и не имитирует экран отсутствующего пользователя. Если Windows полностью удалила графическую поверхность отключённого RDP-сеанса, постоянный экран требует подписанного виртуального display-драйвера либо отдельно включаемого RDP-bootstrap по политике организации.

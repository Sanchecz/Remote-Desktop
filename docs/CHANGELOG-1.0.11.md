# RemoteIt 1.0.11

## Ctrl+Alt+Delete

- Windows Agent постоянно включает разрешение Software SAS для системной службы, сохраняя сторонние биты политики;
- системная служба направляет Secure Attention Sequence в закреплённый интерактивный сеанс Windows через документированный сервисный режим `SendSAS(FALSE)`;
- команда SAS выполняется независимо от доступности обычного пользовательского рабочего стола и поэтому не блокируется экраном Winlogon;
- панель получает номер команды и показывает успех только после подтверждения Agent;
- ошибки системной службы и тайм-аут подтверждения явно отображаются администратору вместо ложного сообщения об успехе.

## Проверки выпуска

- тесты, `go vet` и сборка Agent и Server;
- тесты мобильной клавиатуры, камеры, масштабирования и MCP-инструкции;
- production-сборка TypeScript/Vite;
- release-сборка Android APK с повышенным `versionCode`;
- сквозной тест команды на реальном Windows Agent с проверкой защищённого экрана;
- синхронная версия `1.0.11` во всех публикуемых компонентах и manifest-файлах.

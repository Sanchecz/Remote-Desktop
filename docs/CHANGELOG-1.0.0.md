# RemoteIt 1.0.0

Первый стабильный переносимый релиз RemoteIt.

## Основное

- единая панель управления устройствами, пользователями, токенами и журналом;
- Windows, Windows Server, Ubuntu/Linux и macOS агенты;
- Windows Agent с системной службой, tray-интерфейсом и автоматическим обновлением;
- удалённый экран с режимами Auto/15/30/60 FPS, масштабированием и вводом мыши/клавиатуры;
- мобильный адаптивный интерфейс и Android APK;
- терминал PowerShell/CMD/Bash/Zsh с корректным выбором по ОС;
- передача файлов частями до 10 ГБ с восстановлением после ошибки;
- защищённые токены установки, роли и журналирование действий;
- переносимый Docker-релиз без паролей, приватных ключей, базы и пользовательских файлов.

## Исправления перед 1.0.0

- исправлена передача клавиш с Shift и знаков пунктуации;
- добавлены тесты русской и латинской раскладки удалённой клавиатуры;
- исправлен откат файла при ошибочном или слишком большом блоке передачи;
- улучшена мобильная форма входа и минимальные размеры интерактивных элементов;
- согласованы версии Windows, Android, MCP, PWA и всех агентов.

## Проверки

- Go format, vet, unit и race-тесты server/agent;
- TypeScript, Vite production build и web unit-тесты;
- изолированный API smoke-тест с отдельной PostgreSQL и Docker-сетью;
- проверка выдачи Remote ID, heartbeat, команд и файловых заданий;
- проверка SHA-256 всех публикуемых установщиков и APK;
- post-deploy health и контроль неизменности production-базы.

> Windows-бинарники пока не подписаны коммерческим Authenticode-сертификатом. Код и контрольные суммы проверены, но SmartScreen может показывать предупреждение до добавления доверенной подписи.

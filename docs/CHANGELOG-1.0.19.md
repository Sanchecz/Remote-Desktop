# RemoteIt 1.0.19

## Удалённый доступ на телефоне

- Компактное управление теперь определяется не только по типу указателя, который сообщает браузер, но и по фактическому размеру видимой области.
- Альбомный режим сразу открывается с полным удалённым рабочим столом в масштабе «По размеру», даже если телефон повернули до начала сеанса.
- Исправлен крайний случай Android WebView и мобильных браузеров, которые ошибочно сообщают о наличии точного указателя и оставляют раскрытую панель управления.
- При повороте клавиатура закрывается, масштаб и смещение сбрасываются, а компактная панель остаётся доступной поверх полного изображения.

## Управление курсором

- Сохранено дробное накопление движения тачпада: медленное движение больше не залипает между пикселями и не отправляется рывком.
- Добавлено ограниченное адаптивное ускорение для длинных жестов без потери точности коротких перемещений.

## Проверки

- Добавлен тест компактного альбомного режима для WebView с ложным fine-pointer.
- Набор web-тестов расширен до 33 проверок клавиатуры, курсора, масштабирования, ориентации, реконнекта и интеграции Codex.

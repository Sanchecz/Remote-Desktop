# RemoteIt 1.0.35

## Исправление ложного правого клика

- Устранено открытие контекстного меню сразу после входа в удалённый сеанс.
- Agent больше не отправляет одиночный `RIGHTUP` при включении управления, смене FPS или видимости удалённого курсора.
- Состояние кнопок мыши и системных клавиш отслеживается после успешного ввода; при потере сети или смене сеанса освобождаются только действительно нажатые Agent клавиши и кнопки.
- Смена сеанса синхронизирована с обработчиком ввода, поэтому старый пакет не может пересечь границу нового подключения.
- На сенсорных устройствах жест, которым открыли сеанс, никогда не распознаётся как удержание для правого клика. Обычный правый клик долгим удержанием и быстрым касанием двумя пальцами сохраняется со следующего самостоятельного жеста.
- Нативное контекстное меню браузера отключено на карточке предпросмотра.

## Проверки

- Добавлены регрессионные тесты границ сеанса и учёта реально нажатых кнопок и модификаторов.
- Добавлен тест, запрещающий превращать входной жест в правый клик.
- Проверяются веб-интерфейс, Agent, сервер, production-сборка и метаданные версии.

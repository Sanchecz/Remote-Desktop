# RemoteIt 1.0.20

## Точное управление на любых разрешениях

- Каждое событие мыши теперь содержит размер именно того кадра, по которому оно было создано. Переключение потокового профиля между 4K, 2K, Full HD и уменьшенным интерактивным кадром больше не меняет координаты уже отправленного события.
- Windows Agent переводит координаты из пространства кадра в виртуальный рабочий стол с учётом нестандартного разрешения, нескольких мониторов и отрицательного смещения экрана.
- Мобильный курсор сохраняет нормализованную позицию при смене геометрии JPEG, повороте телефона и реконнекте. Отрисовка курсора перенесена в композиторный transform без принудительного layout на каждом движении.
- Добавлены проверки для 1366x768, 1920x1080, 2256x1504, 2560x1440, 2560x1600, 3440x1440, 3840x2160 и вертикального 1080x1920 на телефонных viewport в портретной и альбомной ориентации.

## Передача файлов

- Размер потоковой части увеличен до 64 МБ, при этом файл до 10 ГБ по-прежнему не загружается целиком в память браузера, сервера или Agent.
- Добавлен реальный прогресс отправки внутри части файла, скорость, оценка оставшегося времени и отмена операции.
- Загрузка автоматически продолжает работу с подтверждённого сервером смещения после краткого сетевого обрыва и не дублирует уже принятые данные.
- Направления подписаны явно: с устройства администратора на удалённый компьютер и с удалённого компьютера в загрузки администратора.

## Проверки

- 41 автоматическая web-проверка клавиатуры, координат, курсора, масштабирования, ориентации, реконнекта, файлов и интеграции Codex.
- TypeScript type-check и production-сборка Vite.
- Изолированные Go tests, Go vet и кросс-сборка Agent/Server для Windows и Linux.
- Отдельные проверки checkpoint, прогресса, отмены, сетевого конфликта и некорректного ответа при передаче файлов.

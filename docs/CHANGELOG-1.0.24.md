# RemoteIt 1.0.24

## Мобильное масштабирование

- удалённый кадр больше нельзя увести жестом за границу видимой области и открыть крупный чёрный прямоугольник;
- в портретном режиме неизбежные поля остаются центрированы, а после поворота в горизонтальный режим кадр заполняет доступную ось без скачка;
- масштабирование и автоматическое сопровождение курсора сохраняют доступ ко всем краям рабочего стола, но не оголяют фон.

## Отрисовка кадров

- новый JPEG сначала декодируется и назначается резервным фоном слоя, поэтому Android Chromium/WebView не показывает пустую GPU-плитку при смене кадра во время pinch-zoom;
- предыдущий blob-кадр освобождается только после двух завершённых отрисовок, а при закрытии сеанса ожидающие URL удаляются немедленно;
- убраны конфликтующие `paint containment` и `backface-visibility` у масштабируемого изображения, вызывавшие артефакты на отдельных мобильных GPU.

## Проверки релиза

- 85 Web unit-тестов, TypeScript и production Vite build;
- матрица zoom 100–400% для портретных, горизонтальных и нестандартных размеров;
- визуальный стресс-тест 390×760 и 844×342 с непрерывной сменой JPEG и поворотом туда-обратно;
- Go tests/vet для Server, MCP и Agent, Android debug/unit build и обязательная production-подпись APK в контейнерной сборке.

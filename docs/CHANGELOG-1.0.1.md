# RemoteIt 1.0.1

Стабилизирующий выпуск после RemoteIt 1.0.0.

## Исправлено

- устранена гонка автообновления Linux/macOS-агента под systemd и launchd;
- загруженный бинарник дополнительно проверяется запуском команды `version`;
- обновление устанавливается атомарной заменой файла до штатного перезапуска службы;
- добавлена синхронизация файла и каталога, чтобы обновление не потерялось при аварийном отключении;
- сохранены все функции, интерфейсы и форматы данных выпуска 1.0.0.

## Совместимость

- база данных и конфигурация 1.0.0 совместимы без миграций;
- Windows, Linux и macOS получают 1.0.1 через штатное автообновление;
- релиз 1.0.0 остаётся неизменным архивным выпуском.

# RemoteIt 1.0.22

## Мобильное управление

- Backspace и Delete удаляют текст, уже существовавший на удалённом компьютере, даже когда локальное поле мобильной клавиатуры пусто;
- ввод Android IME, композиция текста и отправка Enter остаются независимыми, без двойного удаления;
- компактные кнопки колеса стали прозрачнее и поддерживают удержание для непрерывной прокрутки;
- канал указателя на телефоне работает с интервалом 8 мс и не зависит от частоты видеопотока.

## Удалённый экран

- Auto по-прежнему начинает с безопасных 30 FPS, но на устойчивом быстром соединении повышается до 60 FPS после двух секунд подтверждённой пропускной способности;
- при ухудшении канала сохраняется быстрое понижение частоты, поэтому кадры не накапливаются в очереди и не увеличивают задержку;
- закреплена проекция координат для нестандартных, портретных, 4K, ультрашироких и смещённых виртуальных рабочих столов.

## Проверки

- unit-тесты мобильной клавиатуры, камеры, масштабирования, поворота, реконнекта и файлов;
- Go-тесты Agent, Server и MCP, включая стресс-матрицу координат указателя;
- production web build, Windows/Linux/macOS Agent, Console, MCP и подписанная Android APK;
- проверка манифеста, SHA-256 артефактов, healthcheck и безопасного отката release-ссылки.

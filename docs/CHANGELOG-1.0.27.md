# RemoteIt 1.0.27

## Удалённый экран и VDI

- полноэкранный режим на компьютере снова показывает весь удалённый монитор без увеличения, обрезанных краёв и скрытой панели задач;
- после RDP/VDI-переподключения Agent принудительно получает новый input-desktop handle, даже если Windows оставила прежнее имя `Default`;
- во время восстановления сохраняется последний корректный кадр, повторные попытки ограничены по частоте, а полностью зависший модуль захвата автоматически перезапускается без завершения пользовательского сеанса;
- краткий обрыв браузера, перезагрузка страницы или поворот телефона возобновляют прежнюю активную сессию; явная кнопка «Завершить» по-прежнему закрывает её окончательно.

## Проверки

- полная Web-матрица координат, кадров, мобильных viewport, reconnect, клавиатуры и файлов плюс production Vite build;
- Go test для Agent, Server и MCP, Windows capture/input tests и `go vet`;
- Android lint и release-сборка обоих APK;
- production candidate health-check, сохранение неизменных БД/Caddy и проверяемый откат приложения.

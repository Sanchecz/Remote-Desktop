# RemoteIt 1.0.28

## VDI и RDP

- модуль удалённого экрана запускается с настоящим WTS-токеном закреплённого Windows-пользователя, поэтому после RDP-переключения захват остаётся в правильном WinStation, а не возвращается в session 0;
- перепривязка к сменившемуся Windows-сеансу выполняется каждые 2 секунды, а полностью устаревшая графическая поверхность заменяется отдельным процессом через 4 секунды;
- временно отсутствующий кадр VDI больше не публикуется как окончательная красная ошибка и не завершает браузерный сеанс: тот же viewer автоматически продолжает работу после восстановления поверхности;
- привязка по SID и запрет показа чужого пользователя сохранены.

## Общий буфер обмена

- двунаправленный текстовый/PNG-буфер Windows включён по умолчанию сразу при подключении;
- первый уже скопированный элемент переносится в удалённый сеанс из того же пользовательского жеста, которым открывается подключение;
- на macOS `Cmd+C`, `Cmd+X` и `Cmd+V` преобразуются в Windows-команды без отправки клавиши Win; Safari использует отложенный ClipboardItem в пределах разрешённого жеста;
- при ограничениях браузера ожидающее удалённое значение записывается во время следующего клика/нажатия, не прерывая экран и управление;
- создание PNG-снимка больше не выключает общий буфер.

## Файлы

- локальный файл можно перетащить прямо на удалённый экран; он потоково загружается на рабочий стол закреплённого Windows-пользователя;
- поверх экрана отображаются понятная зона отпускания, имя, объём и прогресс передачи;
- путь рабочего стола вычисляется по закреплённому SID и профилю Windows, а не по системному профилю службы.

# RemoteIt 1.0.34

## Понятный буфер обмена

- Убрано неоднозначное действие `Синхронизировать буфер`.
- Кнопка `Буфер обмена` открывает два явно направленных действия: `С этого устройства → удалённый ПК` и `С удалённого ПК → это устройство`.
- Каждое действие поясняет, где находится исходный буфер и на каком устройстве он появится.
- Если с удалённого компьютера уже пришли новые данные, направление получения выделяется и помечается как `Новые данные`.
- Автоматический двусторонний обмен остаётся включённым; ручные действия нужны только для явного повтора или когда браузеру требуется пользовательское подтверждение.
- Ручная передача поддерживает текст и PNG-изображения и сообщает понятный результат или причину отказа браузера.

## Проверки

- Добавлен регрессионный тест, запрещающий возвращение неоднозначной подписи и фиксирующий оба направления.
- Проверены типизация, production-сборка интерфейса и тесты очереди текста/изображений.

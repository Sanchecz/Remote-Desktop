# RemoteIt 1.0.21

## Удалённый доступ

- устранён редкий скачок мобильного курсора при переключении нового JPEG-кадра;
- координаты прямого касания и удержания передаются вместе с размером исходного кадра;
- повторная проекция координат между idle/interactive-профилями больше не накапливает погрешность у границ экрана;
- режимы `Auto`, `15 FPS` и `30 FPS` используют качественное билинейное масштабирование даже во время управления;
- быстрый realtime-масштабатор применяется только в режиме `60 FPS`;
- плавающие кнопки прокрутки уменьшены до компактного размера и занимают меньше рабочей области.

## Передача файлов

- возобновление загрузки проверяет точную границу подтверждённого блока;
- сервер не оставляет неподтверждённые байты при ошибке сохранения контрольной точки;
- добавлены проверки повреждённых и опережающих контрольных точек.

## Проверки

- тесты координат, повторной проекции, смены профиля потока и нестандартных разрешений;
- web unit/type/build checks;
- Go test/vet для Agent, Server и MCP;
- Windows amd64 build/test compile;
- production-сборка Windows Agent с libjpeg-turbo и подписанная Android APK.

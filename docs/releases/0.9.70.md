# RemoteIt 0.9.70

Финальный выпуск исправляет масштаб Agent на реальных Windows-дисплеях и включает все изменения 0.9.69.

## Что изменилось

- Окно Windows Agent теперь рассчитывается по физической рабочей области монитора, занимает не более 84% ширины и 82% высоты и всегда целиком помещается на экран.
- Макет сохраняет пропорции утверждённого дизайна; карточки действий имеют фиксированную высоту и больше не растягиваются до низа окна.
- Окно нельзя максимизировать или растягивать, поэтому композиция и размеры элементов остаются стабильными.
- При входе в удалённый сеанс первым и активным выбран режим «Курсор», затем «Касание»; обычный курсор мыши на ПК остаётся видимым.
- Пароли учётных записей могут содержать от 4 до 256 любых символов, без обязательных специальных знаков.
- Удалён дублирующий ручной запуск Agent после установки; фоновая служба управляет единственным интерактивным экземпляром и корректно применяет автообновления.

## Проверка

- Полная Docker-сборка сервера, Web, Windows/Linux/macOS Agent и подписанного Android APK.
- Go-тесты и `go vet`.
- Проверка SHA-256 всех опубликованных файлов.
- Проверка фиксированной геометрии Windows Agent и production healthcheck.

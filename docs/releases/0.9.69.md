# RemoteIt 0.9.69

Дата выпуска: 13 августа 2026 года.

## Что изменилось

- Окно Windows Agent приведено к утверждённому макету размером 1450×1085 пикселей. Растягивание, уменьшение и разворачивание окна отключены, поэтому карточки, логотип и значки больше не деформируются.
- В карточке готовности Agent используется отдельный крупный зелёный индикатор с белой галочкой. Размеры навигации, устройства, быстрых действий, состояния системы и недавней активности сохраняются при каждом запуске.
- Исправлена смена интерфейса после автоматического обновления: служба завершает старые интерактивные процессы и запускает ровно один Agent новой версии вместо оставшегося старого окна или дубликата.
- При входе в удалённый сеанс первым и активным режимом является «Курсор»; «Касание» расположено вторым.
- На настольном компьютере виден обычный локальный указатель мыши. На смартфоне виртуальный указатель отображается в режиме «Курсор» и скрывается в режиме «Касание».
- Сенсорный экран ноутбука больше не переводит настольный браузер в мобильную схему управления: тип интерфейса определяется по основному указателю устройства.
- Пароли учётных записей теперь принимаются длиной от 4 до 256 символов. Спецсимволы, цифры и заглавные буквы не являются обязательными.
- Версии Windows Agent, установщика, веб-приложения и Android APK синхронизированы как `0.9.69`; Android `versionCode` повышен до `84`.

## Проверки выпуска

- тесты и `go vet` сервера и Agent;
- production-сборка TypeScript/Vite;
- кросс-сборка Windows Agent, Setup, Console, Linux и macOS Agent;
- сборка и проверка release-подписи Android APK;
- проверка фиксированной геометрии Windows Agent и версии исполняемого файла;
- проверка `/healthz`, страницы входа, манифеста обновления Agent и SHA-256 опубликованных файлов;
- проверка автоматического перехода подключённых Windows Agent на новую версию.

## Перенос на другой сервер

Исходный код не содержит рабочих паролей, токенов, SSH-ключей, базы данных или закрытого Android signing key. Для переноса действующей системы вместе с пользователями, устройствами и журналом создайте закрытый state-архив командой `ops/remoteit-export-state` и восстановите его согласно [`docs/MIGRATION.md`](../MIGRATION.md).

## Подпись Windows

Windows EXE пока не имеют коммерческой Authenticode-подписи. SmartScreen может предупреждать о новом файле; устранить это только изменением интерфейса или имени файла невозможно — необходим сертификат подписи кода.

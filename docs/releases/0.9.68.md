# RemoteIt 0.9.68

Дата выпуска: 13 августа 2026 года.

## Что изменилось

- Полностью переработан интерфейс Windows Agent по утверждённому бело-зелёному макету: фирменный знак, панель навигации, карточка устройства, состояние подключения, быстрые действия, состояние системы и недавняя активность.
- Все размеры Agent привязаны к единой шкале. DPI Windows, масштаб 125/150/200% и изменение доступного размера окна больше не растягивают отдельные значки, шрифты или карточки независимо друг от друга.
- Для окна с другим соотношением сторон сохраняются пропорции макета; свободная область используется как поле, а не для деформации интерфейса.
- Исправлен курсор в удалённом доступе: на настольном компьютере виден локальный курсор администратора; скрытие применяется только к мобильному режиму виртуального тачпада, где отображается удалённый указатель.
- Версия Windows Agent, установщика, веб-приложения и Android APK синхронизирована как `0.9.68`.
- Android `versionCode` повышен до `83`, обновлён кэш PWA/Service Worker.
- В Windows manifest включена Per-Monitor V2 DPI awareness для корректного отображения Agent на нескольких мониторах с разным масштабом.

## Проверки выпуска

- тесты Go для Agent и сервера;
- production-сборка веб-интерфейса;
- сборка Windows Agent, Windows Setup и Console;
- сборка и проверка подписи Android APK;
- визуальная проверка Agent в базовом и уменьшенном масштабе;
- проверка SHA-256 и размеров опубликованных установщиков;
- проверка `/healthz`, страницы входа и манифеста выпуска после развёртывания.

## Перенос на другой сервер

Исходный код этого тега не содержит рабочих паролей, токенов, SSH-ключей, базы данных или закрытого Android signing key. Для переноса действующей системы вместе с пользователями, устройствами и журналом дополнительно создайте закрытый state-архив командой `ops/remoteit-export-state`. Порядок восстановления описан в [`docs/MIGRATION.md`](../MIGRATION.md).

## Ограничения подписи Windows

Windows EXE пока не имеют коммерческой Authenticode-подписи. Поэтому SmartScreen может предупреждать о новом файле, даже если его SHA-256 совпадает с опубликованной контрольной суммой. Интерфейс или имя файла не могут заменить сертификат подписи кода.

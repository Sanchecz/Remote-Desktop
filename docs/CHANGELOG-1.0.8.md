# RemoteIt 1.0.8

## Удалённый доступ

- исправлена системная отправка `Ctrl+Alt+Delete`: служба Windows направляет Secure Attention Sequence именно в закреплённый пользовательский сеанс;
- сохранено разделение обычного ввода и привилегированной SAS-команды;
- добавлена явная обратная связь после передачи команды системной службе;
- мобильный режим «Курсор» включён по умолчанию и показывает локальный указатель;
- режимы «Курсор» и «Касание» переключаются без залипания перетаскивания;
- масштабирование двумя пальцами удерживает точку под пальцами, допускает переход к нижним областям рабочего стола и больше не возвращает изображение к центру;
- компактную панель можно полностью скрыть и вернуть отдельной кнопкой;
- кнопка экранной клавиатуры остаётся доступной поверх сеанса при скрытой панели, масштабировании и повороте экрана;
- ввод Android передаётся в реальном времени, включая Backspace и исправления IME, без обязательного нажатия Enter.

## Проверки выпуска

- тесты Web для клавиатуры, камеры и инструкции MCP;
- production-сборка TypeScript/Vite;
- тесты, `go vet` и сборка Agent и Server;
- release-сборка Android APK с повышенным `versionCode`;
- синхронная версия `1.0.8` во всех публикуемых компонентах и manifest-файлах.

# RemoteIt 1.0.37

## Исправлено

- Windows Agent больше не использует массовое TCP-сканирование портов при поиске устройств локальной сети. Обнаружение выполняется через короткую ICMP-проверку и системную таблицу соседей Windows.
- Устранено ложное срабатывание Microsoft Defender `Trojan:Win32/Bearfoos.A!ml`, которое блокировало нативную Windows-сборку 1.0.36 после автоматического обновления.
- Сохранены нативные DXGI/libjpeg-turbo, VDI-восстановление после RDP-переподключения, RDP/SSH-действия и управление принтерами.

## Безопасность выпуска

- Windows Agent проверяется Microsoft Defender до публикации и до установки.
- Автоматическое обновление разрешается только после проверки SHA-256 артефактов.
- Сборка 1.0.36 не должна повторно публиковаться: сервер должен предлагать 1.0.35 до готовности 1.0.37.
